# Before you begin

1. Run `npm install`
1. Create `.env` file in repoitory root (don't worry it is ignored by `.gitignore`)
1. Run `npm run dev`
1. Alternatively using VSCode you can click <kbd>F5</kbd> to attach VSCode debugger
